# 岩芯样本切片实验室

运行：

```bash
npm start
```

访问 `http://localhost:3025`：

- `/` —— 原样本/切片工作台：样本创建、切片任务、制片步骤记录、交付统计（旧入口与旧 API 完全保留）。
- `/micro` —— 显微影像采集与二维测量工作台。

## 显微影像与测量流程

1. **选择切片**：在 `/micro` 下拉中选择已有切片（也可从旧工作台切片旁的“显微影像 →”进入）。
2. **标尺校准**：登记镜头倍率（40/100/200/400×）、标尺长度(µm)与标尺像素长度、视野网格行列数和相邻视野重叠率，得到 `1 px = n µm`。标尺必须为**有限正数且在合理量程内**（Infinity/NaN/负数/超量程一律 422 拒绝，不会产生 null 的 µm 结果）。产生测量记录后校准锁定；改网格/重叠率前需先清空视野。
3. **视野上传**：按行优先位置 `行-列`（如 `0-0`）上传 PNG（灰度/RGB/RGBA、8 位、非隔行）。服务端自动：
   - SHA-256 识别重复图片；
   - 拉普拉斯方差判定清晰度（虚焦不合格的视野仍可登记但阻止拼图/测量）；
   - 同一视野并发上传只成功一次（串行化事务）；
   - 非 PNG、PNG 结构/CRC/**压缩数据损坏**、过小、尺寸不一致一律返回可理解的 422 校验错误（不是 500），失败不留半张图或记录。
4. **拼图质检**：覆盖完整且全部清晰后，按重叠位置做 ZNCC 模板匹配并羽化融合成完整薄片图；缺图、虚焦、乱序（在声明重叠位置对不上且能与其他视野高相关匹配）、对不齐都会阻断拼图。
5. **二维测量**：在薄片图上做点、线、多边形面积测量。记录同时保存**原始像素坐标**和 µm 换算结果；图外点、零长度线、退化（共线）面积、跨切片坐标一律失败，且失败不落库。面积顶点会自动折叠**连续重复点/与起点重合的闭合点**（浏览器双击闭合产生的重复终点不会入库）。

## 隔离与输入校验

- 切片编号采用白名单字符集（支持中英文/数字及空格、点、下划线、连字符），拒绝路径分隔符、`..`、点号开头、NUL/控制字符；URL 编号先解码再校验，存储层对每条图片路径再做一次影像目录包含性断言，任何编号都无法把文件写到数据目录之外。

## 数据与可靠性

- JSON 数据原子写入（tmp + rename）；图片先写私有临时文件再原子落位。
- 拼图替换为两阶段提交（暂存 → 备份旧图 → 落新图 → 提交元数据），任何环节失败或进程崩溃都会在启动时（`reconcile`）恢复旧图、清理临时/孤儿文件。
- 所有写操作经进程级互斥队列串行化；重启后校准、视野、拼图、测量均不丢失。
- 可用 `DATA_DIR`（默认 `./data`）与 `PORT`（默认 3025）覆盖存储位置和端口。

## 测试

```bash
npm test          # 合成夹具 + PNG 编解码单测 + 端到端流程 + 浏览器事件复测
```

- `test:codec`：PNG 三种色彩类型 × 五种滤波的解码、编码往返、损坏拒绝。
- `test:e2e`：真实启动服务器（隔离临时 DATA_DIR），覆盖校准、拼图、测量换算、异常阻断、8 路并发重复上传、故障回滚、崩溃恢复与重启持久化，以及安全反例（非有限/超大标尺、损坏 PNG、切片编号路径穿越、面积重复顶点）。
- `test:browser`：抽取工作台页面真实内联脚本，在 DOM/Canvas/fetch 沙箱中重放浏览器的 `click→click→dblclick` 事件序列，验证双击闭合面积时终点不重复。
